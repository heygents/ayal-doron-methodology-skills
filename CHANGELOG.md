## 1.0.0 — 2026-09-09

First release.

### Added
- **`/00-win-challenge-intake`** — conversational intake (who, challenge verbatim, tried, constraints, 7-second anchor, uncertainty ladder) → Challenge Card in `Outputs/Win/<slug>/challenge-card.md` → routing table to the right tool.
- **`/01-win-irreplaceable-anchor`** — the anchor: 7-second test, forbidden answers, "call Ruti" test, six-criteria scoring, weekly sharpening, ladder jump.
- **`/02-win-almost-absurd-goal`** — Tool 1: escalation grammar, five quality tests, primitive redefinition, three new-field directions.
- **`/03-win-extreme-obstacle`** — Tool 2: multiplication table, breaking point, coffee pause, "what does the groom actually do?", three-level solution ladder.
- **`/04-win-extreme-persona`** — Tool 3: contrasting persona bank, 60-second corridor walk, "chicken for a shekel" single message, translation back.
- **`/05-win-calculated-knockout`** — Tool 4: supreme-goal question, field map (already taken / customer pays / come to them / "we'll go bankrupt" / already lying here), hindsight sentence, honest downside, bold-idea/cautious-execution pilot, next knockout.
- **`/06-win-habit-infrastructure`** — habits with cadence and environment change, contagion protocol (90-minute isolation), stop/keep/forget, 90-day check.
- **`references/ayal-doron-examples.md`** — shared principles and examples bank from the Elementor Day lecture (9 Sep 2026).
